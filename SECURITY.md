# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 2.x (`@dotpress/*`, prereleases included until 2.0.0) | ✅ |
| 1.x (`dotpress`, `@dotpress/auth` 1.x) | ❌ frozen, no fixes |

Security fixes are released for the latest 2.x version only. Users of 1.x should migrate to 2.x.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues, discussions or pull requests.

Report them privately through GitHub: [**Report a vulnerability**](https://github.com/dotpressjs/dotpress/security/advisories/new) (the *Security* tab of the repository). If you cannot use GitHub, email [security@dotpress.dev](mailto:security@dotpress.dev).

Please include:

- the affected packages and versions;
- a description of the issue and its impact;
- the steps or a minimal code sample to reproduce it;
- a fix or a mitigation, if you have one.

## What to expect

- An acknowledgement within 3 business days.
- An assessment, and a fix or a mitigation plan, as soon as possible depending on the severity.
- A security advisory published with the fixed version, crediting you unless you prefer otherwise.

Please give us a reasonable time to release a fix before disclosing the issue publicly.
